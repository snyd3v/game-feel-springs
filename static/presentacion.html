Una animación como masa, resorte y amortiguador

El resorte tira hacia el destino

Fr = −k(x − xf)

El amortiguador frena según la velocidad

Fa = −c x′

Segunda ley de Newton

m x″ = −k(x − xf) − c x′

Con ω = √k/m  y  ζ = c / (2mω)

x″ + 2ζω x′ + ω²(x − xf) = 0

ω controla la rapidez · ζ controla el carácter

Cambio de variable y ecuación característica

1. La hacemos homogénea

u = x − xf

Como xf es constante:

u′ = x′ ,   u″ = x″

Reemplazo:

u″ + 2ζω u′ + ω²u = 0

2. Ensayamos u = ert

ert(r² + 2ζωr + ω²) = 0

ert ≠ 0 , por lo tanto:

r² + 2ζωr + ω² = 0

Fórmula del estudiante:

r = −ζω ± ω√ζ² − 1

El signo de ζ² − 1 decide cómo se mueve

Ejercicio b): ζ = 1 con condiciones iniciales

ω = 8 rad/s  ·  x(0) = 0  ·  x′(0) = 0  ·  xf = 1 m

Solución general

u″ + 16u′ + 64u = 0

ert(r² + 16r + 64) = 0

(r + 8)² = 0

r = −8 (multiplicidad 2)

u = (C1 + C2t) e−8t

Aplico las condiciones iniciales

u(0) = 0 − 1 = −1 ⟹ C1 = −1

u′ = C2e−8t − 8(C1 + C2t)e−8t

u′(0) = C2 − 8(−1) = 0 ⟹ C2 = −8

Por lo tanto, como x = u + 1:

x(t) = 1 − (1 + 8t) e−8t

Resorte frente a interpolación lineal (lerp)

Resorte · segundo orden

x″ + 2ζω x′ + ω²(x − xf) = 0

  • Acelera desde el reposo
  • Llega con velocidad: tiene inercia
  • Puede rebotar si ζ < 1
  • Con paso fijo no depende del monitor

Lerp · primer orden

x += (destino − x) · 0.1

  • Arranca con la máxima velocidad
  • Solo frena: no tiene inercia
  • Nunca rebota
  • Por cuadro, depende del monitor:
    se asienta en 0.63 s a 60 Hz y 0.26 s a 144 Hz

El lerp solo conoce la posición. El resorte también conoce la velocidad
