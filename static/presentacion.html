Una animación como masa, resorte y amortiguador

El resorte tira hacia el destino

Fr = −k(x − xf)

El amortiguador frena según la velocidad

Fa = −c x′

Segunda ley de Newton

m x″ = −k(x − xf) − c x′

Divido entre m, con ω = √k/m  y  ζ = c / (2mω)

x″inercia + 2ζω x′amortiguador + ω²(x − xf)resorte = 0

ω controla la rapidez · ζ controla el carácter

Ecuación no homogénea: dos caminos

x″ + 2ζω x′ + ω²x = ω²xf  ·  el lado derecho es una constante distinta de cero

Cambio de variable

u = x − xf

Como xf es constante:

u′ = x′ ,   u″ = x″

Reemplazo:

u″ + 2ζω u′ + ω²u = 0

Coeficientes indeterminados

Ensayo xp = A

r = 0 no es raíz: no hay resonancia

xp′ = 0 ,   xp″ = 0

Reemplazo:  ω²A = ω²xf

xp = xf

Los dos llegan a lo mismo: x = xh + xp = u + xf

Ecuación característica: tres regímenes

Ensayo u = ert  ⟹  ert(r² + 2ζωr + ω²) = 0 ,  con ert ≠ 0

r² + 2ζωr + ω² = 0  ⟹  r = −ζω ± ω√ζ² − 1

ζ < 1 · Subamortiguado

ζ² − 1 < 0: complejas

r = a ± bi

a = −ζω
b = ω√1 − ζ²

u = eat(C1 cos bt + C2 sen bt)

Oscila y se pasa

ζ = 1 · Crítico

ζ² − 1 = 0: multiplicidad 2

r = −ω

La segunda solución
se multiplica por t

u = (C1 + C2t) e−ωt

Lo más rápido sin oscilar

ζ > 1 · Sobreamortiguado

ζ² − 1 > 0: reales distintas

r1 ≠ r2

Las dos negativas,
una cercana a cero

u = C1er1t + C2er2t

Llega lento y pesado

Ejercicio b): ζ = 1 con condiciones iniciales

ω = 8 rad/s  ·  x(0) = 0  ·  x′(0) = 0  ·  xf = 1 m

Solución general

u″ + 16u′ + 64u = 0

ert(r² + 16r + 64) = 0

(r + 8)² = 0

r = −8 (multiplicidad 2)

u = (C1 + C2t) e−8t

Aplico las condiciones iniciales

u(0) = 0 − 1 = −1 ⟹ C1 = −1

u′ = C2e−8t − 8(C1 + C2t)e−8t

u′(0) = C2 − 8(−1) = 0 ⟹ C2 = −8

Por lo tanto, como x = u + 1:

x(t) = 1 − (1 + 8t) e−8t

Resorte frente a interpolación lineal (lerp)

Resorte · segundo orden

x″ + 2ζω x′ + ω²(x − xf) = 0

  • Acelera desde el reposo
  • Llega con velocidad: tiene inercia
  • Puede rebotar si ζ < 1
  • Con paso fijo no depende del monitor

Lerp · primer orden

En el código (lab.js):

st.lerp += (st.target - st.lerp) * 0.1;
  • Arranca con la máxima velocidad
  • Solo frena: no tiene inercia
  • Nunca rebota
  • Por cuadro, depende del monitor:
    se asienta en 0.63 s a 60 Hz y 0.26 s a 144 Hz

El lerp solo conoce la posición. El resorte también conoce la velocidad

La ecuación en el programa

De segundo orden a sistema

x′ = v

v′ = −2ζωv − ω²(x − xf)

La misma línea en el código (physics.js · acceleration):

return -2 * zeta * omega * v
       - omega * omega * (x - target);

RK4 con paso h fijo (rk4Step): pendiente k1 al inicio,
k2 y k3 a la mitad y k4 al final del paso

s.x = x + (h / 6) * (k1x + 2 * k2x
                     + 2 * k3x + k4x);

¿En qué se diferencia de la exacta y por qué?

  • La exacta es una fórmula
  • RK4 avanza por pasos y acumula error
  • Ese error es proporcional a h⁴
  • Con h a la mitad, baja unas 16 veces

error ≤ 1.9 × 10−10 m

con h = 0.001 s

Verificación: numérica frente a exacta

err = np.abs(x_num - x_ex) = |xRK4 − xexacta| en los mismos tiempos t  ·  error acumulado de RK4, ∝ h⁴
